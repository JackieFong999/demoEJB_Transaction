demoEJB-Transaction

One Submit writes to two MySQL tables through one @Stateless EJB — committed or rolled back together.

Register a customer

Writes tblCustomer(Cust_Name, Tel) + tblAccount(Cust_Name, 'D', 0.00) inside one container-managed JTA transaction.

What the transaction does

  • Success → both rows commit.
  • Duplicate customer name → primary-key error → both roll back.
  • Business error after both INSERTs → both roll back (see README: forced-failure test).
